FixIt – Smart Campus Complaint & Maintenance Management System is a full-stack web application built with React.js, Vite, Tailwind CSS, Node.js, Express.js, and MongoDB. It streamlines campus maintenance by enabling students to submit complaints, track resolutions, and receive notifications, while administrators manage complaints, assign departments, update priorities, monitor feedback, and analyze performance through interactive dashboards. Features include JWT authentication, role-based access control, image uploads, complaint tracking, and rule-based smart priority suggestions.
